🩺 MediScan AI - AI Healthcare Assistant API

MediScan AI is a Python-based backend service designed for medical scan analysis and intelligent health recommendations.

## 🚀 Features
- **FastAPI Backend:** Lightweight and high-performance API routing.
- **AI/ML Processing:** Integrated computer vision and ML models for diagnostic assistance.
- **RESTful Endpoints:** Easy integration with mobile and web frontends.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** FastAPI
- **Libraries:** MediaPipe, OpenCV, NumPy
